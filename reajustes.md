   - menssagens gcs de níveis críticos,  alaertas e pre arms, deverão aparecer em uma tag na parte inferior do mapa, de forma que seja bem vistas, com cores referente ao nível da menssagem (vermelho para mais criticas,; laranja, amarelo ...)
   - Ao conectar ao drone, caso haja mais de um componente com outro SYSID conectado, ter a opção de escolhar entre os componenes (tipo como era no programa antigo)
3. em flight plan:
    - o botão de save file deverá abrir uma janela para escolhe de onde o arquivo deverá ser salvo
4. em Paramter:
   - o botão de save to file deverá abrir uma janela para escolher onde o arquivo deve ser salvo
